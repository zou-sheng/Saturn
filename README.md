# Saturn

Saturn: An Efficient Mapping and Hardware Co-exploration for DNN Accelerators

### Setup ###
* Download the source code
* Create virtual environment through anaconda
```
conda create --name SaturnEnv python=3.8
conda activate SaturnEnv
```
* Install packages
```
pip install -r requirements.txt
```
* Install [Timeloop](https://timeloop.csail.mit.edu/)

### Run Example ###

```
run_saturn_all.sh
```
